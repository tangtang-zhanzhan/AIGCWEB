# 唐婧 · AIGC 电商视觉作品集

这是一个可离线携带的静态个人作品集网站，包含商品视觉、短视频、平台运营、Skill / Agent 工作流和 3D 人物展示。

## 快速启动（Mac）

1. 解压文件夹。
2. 双击 `启动网站.command`。
3. 浏览器打开后访问 `http://localhost:4173/`。

首次双击时，如果 macOS 提示无法打开，请右键文件并选择“打开”，再确认打开。

## 手动启动

在网站文件夹中打开终端，运行：

```bash
python3 启动网站.py --port 4173
```

然后访问 `http://localhost:4173/`。Windows 用户可将命令中的 `python3` 换成 `python`。

## 使用说明

- 请通过本地 HTTP 服务访问，不要直接双击 `index.html`，否则 `/portfolio/` 资源路径和页面路由可能无法正常加载。
- 关闭终端窗口即可停止服务。
- 3D 人物组件首次加载需要联网获取 `model-viewer` 组件；作品图片、视频、音频和 3D 模型文件已随包提供。
- 网站内容均为作品集展示与模拟交互，不包含需要配置的 API 密钥。
